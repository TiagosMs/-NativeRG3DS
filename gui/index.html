🎮 Guia de Uso & Controles no Anbernic RG DS

Atalhos dos Botões no RG DS

  • Botão FN (Home): Toque rápido abre ou fecha o Menu de Opções durante o jogo.
  • FN + START: Encerra o jogo e volta para o menu do EmulationStation.
  • Botão L2 (Toque Rápido): Alterna entre a tela superior e inferior.
  • FN + R1: Alterna visualização (Duas telas ou tela cheia).
  • Analógico Direito: Move o cursor de toque na tela inferior.
  • Botão R2: Simula o toque na tela onde estiver o cursor.
  • Touchscreen Físico: Funciona diretamente com o dedo ou caneta stylus na tela inferior!

Como Decriptar ROMs de 3DS

O recompiler necessita de arquivos decriptados para ler as instruções nativas:

  1. Insira o cartão SD no seu console 3DS real com CFW (Luma3DS).
  2. Ligue segurando START para entrar no GodMode9.
  3. Navegue até o seu jogo (.3ds ou instalado em SD).
  4. Aperte A e selecione "NCCH image options..." -> "Decrypt file (...)".
  5. Copie o arquivo decriptado para o seu computador e selecione aqui no Studio!
